# Electric Bloom Studio — Vibe Coding for Entrepreneurs

**Build It. Test It. Own It. • Free seven-day learning example • November 9–15, 2026**

A fictional, single-file business landing-page demo built for the free [Vibe Coding for Entrepreneurs community](https://www.facebook.com/groups/1418802503230092/). This resource is for learning, **not** a production website, checkout, or customer-inquiry service.

## NEW: Free Day 1–2 interactive AI Prompt Lab

Use the [standalone offline Prompt Builder](./day1-prompt-builder.html) to turn a fictional business problem into a complete AI coding prompt with explicit guardrails and tests. Read the [Prompt Lab instructions and test notes](./PROMPT_LAB_README.md) first if you are new to saving HTML files. The builder has **no login, AI API, storage, analytics, or outbound network requests**. It generates text you can copy or download locally; it does not send a request to an AI provider.

## Start in under a minute

1. Open [electric-bloom-demo.html](./electric-bloom-demo.html) in this GitHub folder.
2. Select **Raw** and save the page as `electric-bloom-demo.html` (make sure the filename ends in `.html`).
3. Open the downloaded file in your web browser. No account, hosting, or paid AI API is needed.
4. Follow [the seven-day lesson plan](./LESSON_PLAN.md).

The colors, layout and interactions are included inside that one HTML file. The inquiry form performs **local input validation only** and intentionally sends or saves **nothing**. The display is a fictional example, not a real client website. Use sample names/messages and never include payment details, private customer records, passwords or API keys.

## Seven-day learning path

- **Nov 9:** Pick a problem and write an AI-build brief.
- **Nov 10:** Plan one workflow and its review checkpoint.
- **Nov 11:** Test fields, keyboard use, empty inputs and mobile layout.
- **Nov 12:** Write a responsible running-cost checklist.
- **Nov 13:** Add or improve three demo FAQ answers.
- **Nov 14:** Ask for feedback, share screenshots only with permission.
- **Nov 15:** Explain what works, what failed and what needs improvement.
